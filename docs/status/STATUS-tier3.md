# 琅嬛 Tier 3 — 写作与阅读体验

提交后请 `git pull`，本地 `npm i && npm run build`（或 `npm run dev`）验收。

## 已实现

1. **CodeMirror 6 Markdown 编辑器**（`src/components/editor/MdCodeMirror.tsx`）
   - 语法高亮、行号、查找替换（⌘/Ctrl+F）、历史撤销
   - `/` 斜杠命令（标题、列表、双链、嵌入、模板片段等）
   - `[[` 文档补全
   - 粘贴 / 拖入图片 → IndexedDB 附件 + 插入相对路径 `![](...)`
   - HTML 仍走原 IDE 暗色镜像，**分栏滚动同步 / 选区定位不回归**

2. **混合模式「混合」**（`MixedMdView.tsx`）
   - 顶栏预览|分栏|源码|**混合**（仅 MD）
   - 非活动块渲染 Markdown；当前块为源码 textarea（Typora 风格 MVP）
   - 分块规则（`src/lib/mdBlocks.ts`，2026-11 收紧）：
     1. 围栏代码整体成块 —— ``` / ~~~ 都认，闭合围栏须同字符且不短于开头，
        所以 ```` 里的 ``` 只是内容；块内空行不切
     2. `$$` 公式块与表格整体成块，且不与相邻正文粘连（即使前后无空行）
     3. 标题永远独占一块（标题前、标题后紧接的正文都另起块）
   - 仍是「空行分块」：松散列表照旧拆开；回写走 `joinMarkdownBlocks`

3. **图片与附件**
   - `AssetMeta` + IDB blob；路径助手 `src/lib/assets/paths.ts`
   - 预览用 `AssetImage`；侧栏 `AssetsPanel`
   - 全库 zip 备份含附件；文件夹同步写出二进制（`syncOutAll` / 即时 write-through）

4. **阅读增强**
   - 字号 / 行宽持久化（顶栏 + ⌘K）
   - MD **专注模式**（F / Esc，隐藏侧栏顶栏状态栏）
   - 脚注样式（GFM）；大纲可折叠嵌套；Mermaid / KaTeX / 行号保持

5. **划线与批注**
   - 预览选区浮条「划线批注」；不改正文
   - 侧栏可编辑笔记 / 删除；预览软高亮 `mark.lh-annot-*`
   - 改文后**不静默贴错段**：高亮落点先用 reanchor 偏移锁定所在块，块内多次出现才按
     距离挑最近一次；分不清就不亮，只在侧栏保留并说明原因（找不到原文 / 同文多处 /
     所在小节已改）。状态栏会明确提示「原文已变」
   - 批注可带可选 `heading` 锚（创建时记录所在小节）；小节整体消失时判失效，
     旧数据没有该字段则保持原行为

## 验收步骤

1. 打开任意 `.md` → **源码**：确认 CM6（行号、暗/纸主题下可读）；输入 `/` 选命令；⌘F 查找。
2. 源码中粘贴一张图片 → 正文出现 `![](./assets/...)`；侧栏「附件」可见；预览能显示图。
3. 顶栏切 **混合**：点一块可编辑，点另一块恢复渲染；保存后预览/源码一致。
   分块验收：```` ``` ```` 里留空行、`$$` 里留空行、表格紧贴正文、标题下一行紧接
   正文 —— 四者都不该被错误拆开或粘连（`src/lib/mdBlocks.test.ts`）。
4. 预览选中一段 → 「划线批注」→ 侧栏出现批注；改笔记不改正文。
   改文验收：在高亮句**之后**改一个字 → 仍应高亮原位不改段；把高亮句或所在小节删掉 →
   正文不再高亮、侧栏指出原因、状态栏出现「原文已变」。
5. 调字号/行宽，刷新后仍在；按 **F** 进专注，**Esc** 退出。
6. 脚注：正文 `文本[^1]` + `[^1]: 注` 应在文末列出。
7. HTML 页：分栏滚动同步、定位源码、沉浸模式仍可用。
8. `npm test` / `npx tsc --noEmit` / `npm run build` 应全绿。

## 限制

- 混合模式按「空行分块」+ 围栏代码 / `$$` / 表格 / 标题的特殊规则，不是完整
  Typora（不识别松散列表、引用块内部的空行、setext 标题）；超大文档块数多时
  体验一般。
- 批注高亮按 quote 软匹配 DOM 文本。改文后仍可能对不准，但**不再静默贴到错段**：
  正文只在有把握时高亮，否则只留侧栏并说明原因。
- HTML 未切 CM6（有意保留 IDE + 定位）。
- 文件夹同步拉回外部新增二进制附件的「扫入 IDB」仍偏 MVP（写出完整；扫入以文档为主）。
