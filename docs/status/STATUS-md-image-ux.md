# Markdown 图片体验（说明 / 宽度 / 未引用清理）

上次更新：2026-11-09

## 做了什么

在既有「右键上传图片」之上：

1. **失败可见**：缺失图仍显示「图片未找到」路径与原因；上传校验失败走状态栏中文（类型/大小）。
2. **说明与宽度**：预览中点击图片 →「编辑图片」改 alt（图注）与显示宽度（自动 / 50% / 75% / 100% / 400px）。宽度写入 Markdown title：`"lh-w:50%"`，不改 href。
3. **未引用清理**：附件面板橡皮檫 → 列出全库未被正文引用的附件 → 确认后删除。

## 入口

- `src/lib/assets/mdImageEdit.ts` / `orphanAssets.ts`
- `MdImageEditDialog.tsx` · `AssetsPanel.tsx` · `MarkdownReader` 预览图

## 限制

- 宽度语法为琅嬛私有 title 约定，其它编辑器会当普通 title。
- 清理按路径/文件名启发式匹配引用；非常规相对路径可能误判，确认列表可取消。
- 未做物理安卓 GUI 手测。
