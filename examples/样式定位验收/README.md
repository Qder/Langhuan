# 样式定位验收

这个文件夹是给「点预览元素 → 看它被哪些 CSS 规则命中 → 跳到 `.css` 对应行」准备的**验收现场**，
每个方块只考一个点。用法：

1. 把**整个文件夹**导入（侧栏「导入文件夹」），打开其中的 `index.html`。
2. 按下面清单逐条点，核对右侧「元素检视」抽屉里的**样式**段；点段里任意一条规则，
   应跳到对应 `.css` 的整条规则并高亮。

> 提示：抽屉开在预览右侧，`Esc` 关闭；点别的元素抽屉直接换成那个元素的数据（并列的 HTML / 行为两段也是同一次点击）。

## 清单

| # | 点哪里 | 预期条数 | 要看什么 |
|---|--------|---------|---------|
| ① | 白底卡片（或里面的粗体标题） | **4** | `body div`(0,0,2)、`.card`(0,1,0)、`.card:hover`(0,2,0)、`@media (max-width: 520px)` 里的 `.card`；最后一条带条件徽标，宽屏上还标「当前不生效」。点粗体标题时标签仍是 `div#card.card`（子元素没规则 → 往上找） |
| ② | `#alpha` 那个块 | 3 | 顺序按特异性：`#alpha` → `.alpha` → `body div` |
| ③ | 左边有红线的块 | 2 | `[data-kind="tip"]` 与 `body div`，特异性都是类级 |
| ④ | 绿色底 / 虚线框两块 | 各 2 | `:is(.is-ok, .nope)` 显示 (0,1,0)；`:where(.where-ok)` 显示 (0,0,0) |
| ⑤ | 两个小胶囊 | 2 / 1 | `.chip` 命中 `.chip:not(.off)`；`.chip.off` 只剩 `body div`——`:not()` 是当真在算的 |
| ⑥ | 灰框那一块 | 3 | `@supports` 那条 + `@media` 那条（徽标显示两段条件）+ `body div` |
| ⑦ | 上面有横线的块 | 3 | 两条 `.shared`：一条跳 `css/base.css`，一条跳 `css/extra.css` |
| ⑧ | 点线框 / 橙色虚线框 | 各 2 | 一条来自 HTML 里的 `<style>`、一条来自 `js/app.js` 注入，两条都标「推断」，hover 提示「规则来自动态注入或 HTML 内联样式」；列不出行号 |
| ⑨ | 灰区块 / 链接 | 0 | 样式段显示「没有规则命中这个元素」：`section` 没规则，向上也不会爬到你 `body` 的 margin 上（`html/body/:root` 这类"哪都命中"的规则不参与向上找）；链接这类交互元素不发定位、但抽屉仍会开（HTML / 行为两段照旧） |
| ⑩ | 底部那块 | 2 | `.only-extra` + `body div`，都跳 `css/extra.css`（验证切换文件） |
| ⑪ | 左边有绿边的块 | 3 | 两条 `.dup`（`css/extra.css` 里同条件下写了两遍）+ `body div`。**两条 `.dup` 分别跳各自的源码行**，声明也不一样（一条 `border-left`、一条 `border-left-color`）；以前两条都会跳到第一行 |
| ⑫ | 浅黄底的两块 | 各 2 | `#pick-me, .pick` 只命中 `.pick` 的那块按 **(0,1,0)** 排、并标「命中 .pick」；`id="pick-me"` 那块两支都命中，按 **(1,0,0)** 排、不标分支。选择器本身始终整条展示 |

⑧ 里那个「注入」按钮可以再往页面里加规则：按几次再点橙色虚线框，会多出几条「推断」。

## 这份示例同时验证了这些实现细节

- **选择器匹配**，不是文本搜索：`.card` 规则里没有「卡片」二字，仍然能被认出来。
- **特异性排序**：⑵ ③ ④ 里的顺序与括号里的三元组一致；`:is()` 取参数最大值、`:where()` 记 0。
- **`@media`/`@supports` 嵌套**：⑥ 的两段条件、① 的条件徽标；同一选择器在 `@media` 内外各有
  一条时（`.card`），靠条件区分、不会都跳到同一行。
- **同名规则重复**：⑪ 的两条 `.dup` 条件完全一样，只按「文件 + 选择器 + 条件」查索引会永远
  跳第一条。bridge 会连「同签名第几条」一起报，索引按同一把尺子数出来，所以两条各自落到
  自己的行。对不上号时（样式表被运行时改过、索引过期）宁可标「推断」并**只给文件不给行号**，
  也不猜一个可能是错的位置。
- **逗号列表按命中的那支算**：⑫；`A, B { }` 在层叠里等于两条独立规则，元素只命中 `B` 时
  按 `B` 的特异性参与排序，不是整列最大值。`:is()`/`:not()`/`:has()` 的参数是另一回事——
  按规范取**全部**参数的最大值（所以 `:is(#x, .y)` 即使命中的是 `.y` 也算 (1,0,0)）。
- **来源文件**：⑦ ⑩ 证明「这条规则来自哪个文件」是从内联标记里读出来的，不是猜的。
- **降级**：⑧ 的运行时注入与 HTML 内联 `<style>` 没有索引，只能给「推断」且不给行号。
- **向上找**：① 点粗体字仍然给出卡片的 4 条（子元素没规则时上溯，最多 4 层）；
  ⑨ 说明上溯不会停在 `body` 的 margin 上。
- **行号**：每一条点进去都应高亮**整条规则**（选择器行 → `}`），不是单行。
- **伪元素不参与**：`matches()` 不认 `::before`，点父元素不会列出它的伪元素规则（浏览器本身如此）。
