# 粘贴 / 剪藏验收

本仓库**没有**浏览器扩展；请用应用内能力验证。

## 材料

同目录打开（用系统浏览器双击即可）：

`粘贴用片段.html`

内容含标题、加粗、列表、链接、引用。

## 方式 A：源码编辑器粘贴（Turndown）

1. 在琅嬛新建一篇 Markdown，切到 **源码**
2. 在浏览器打开 `粘贴用片段.html` → **全选 → 复制**
3. 回到源码框 **粘贴**
4. 期望：得到 Markdown（`#` / `**` / `-` / `[文字](url)`），而不是一整坨 HTML 标签

## 方式 B：从剪贴板导入网页

1. 同样复制 `粘贴用片段.html` 的页面内容（或复制任意网页选区）
2. 侧栏 **新建 ▾ → 从剪贴板导入网页**（或命令面板搜「剪贴板」）
3. 期望：在 `剪藏/` 下新建一篇 MD，正文已被清洗转换

## 方式 C：HTML 快照（可选）

命令 / 菜单里的 **保存 HTML 快照** 会尽量保留 HTML；再打开预览，应走 iframe 沙盒（对照 [[安全白名单]] 与 `HTML快照危险演示.html`）。

## 期望对照

| 操作 | 期望 |
| --- | --- |
| 富文本粘进源码 | 转成 MD，脚本/样式被丢掉或弱化 |
| 剪贴板导入网页 | 新文档 + 可读 MD |
| HTML 快照 | 独立 `.html`，沙盒预览 |
