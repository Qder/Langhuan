# 功能验收包

把本文件夹用侧栏 **导入 ▾ → 导入文件夹** 整包导入后，按下面清单逐项点开验证。

> [!tip] 已有知识库
> 种子文档只在**首次**初始化写入。你已经用过琅嬛时，请导入仓库里的 `examples/功能验收/`，不要指望「恢复示例文档」会带上这套新篇。

## 演示文

- [[相对图片]] — 库内 SVG 能显示；缺失 PNG 出占位
- [[双链Peek]] — 悬停卡片；别名与「未找到」
- [[行号与Mermaid]] — 代码行号 + Mermaid 流程图
- [[安全白名单]] — MD 预览清洗危险 HTML
- [[粘贴说明]] — Turndown / 剪贴板导入步骤

HTML 沙盒：打开同目录的 `HTML快照危险演示.html`（文件树里可见）。

## 验收清单

- [ ] 相对图：`seal.svg` 出朱印；`missing.png` 占位并标路径
- [ ] Peek：悬停双链约 0.35s 出卡片；缺失目标显示「未找到」
- [ ] 行号：多行代码左侧有行号；复制不含行号
- [ ] Mermaid：流程图渲成 SVG，可切「源码」
- [ ] 安全：`<script>` / `onerror` 不执行；`<strong>` 仍加粗
- [ ] HTML：沙盒内脚本可自转，不污染外层 UI
- [ ] 粘贴：用 `粘贴用片段.html` 复制后，源码粘贴或「从剪贴板导入网页」得到干净 MD
