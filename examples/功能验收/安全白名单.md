# 安全白名单（Markdown）

本页故意写入若干「不该在预览里执行」的 HTML 片段，用来确认 **rehype-sanitize** 白名单在工作。

> [!note] 说明
> 这是教学用的对照材料，不是攻击教程。预览里危险标签应被剥掉或失效；安全标签仍可渲染。

## 应被清掉 / 失效

下面若出现可点的「假按钮」或弹窗，说明清洗失败（不应发生）：

<script>alert(1)</script>

<img onerror="alert(1)" src="x" alt="事件属性应被剥掉" />

<p onclick="alert(1)">带 onclick 的段落（事件应无效）</p>

## 应保留

这段 **加粗** 与下面的 HTML strong 都应正常显示：

<strong>安全的加粗标签</strong>

还有普通列表：

1. 白名单放行常见排版标签
2. `script`、事件处理器不在白名单内
3. HTML 整页预览另走 iframe 沙盒（见同目录 HTML 演示）

## 期望

| 内容 | 期望 |
| --- | --- |
| `<script>` | 不执行、预览中不可见或已被剥除 |
| `onerror` / `onclick` | 不触发弹窗 |
| `<strong>` | 仍加粗 |

HTML 沙盒请打开文件树中的 `HTML快照危险演示.html`。回到 [[README]]。
