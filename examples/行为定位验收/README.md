# 行为定位验收

这个文件夹是给「点预览元素 → 看它身上绑了哪些事件处理函数 → 跳到源码高亮整个函数」准备的**验收现场**，每个方块只考一个点。用法：

1. 把**整个文件夹**导入（侧栏「导入文件夹」），打开其中的 `index.html`。
2. 按下面清单逐条点，核对右侧「元素检视」抽屉的**行为**段（HTML / 样式两段同一次点击一起给出）。

> 提示：抽屉开在预览右侧，`Esc` 关闭、`↑↓` 换条目、`Enter` 跳转；点别的元素抽屉直接换成那个元素的数据。
> 点条目跳源码时抽屉不会关，返回后那一行仍然是选中的；点图钉可以让抽屉占一列、不压住预览。
> 行为数据来自**静态分析**（acorn 解析 `js/app.js` + 本页内联 `<script>`），不依赖运行时插桩。

## 清单

| # | 点哪里 | 预期（行为段） | 点进去看什么 |
|----|--------|------------------|--------------|
| ① | `保存` 按钮 | `click → onSaveClick` · `js/app.js:12` · 精确 | 高亮第 8–10 行（整个 `onSaveClick` 函数体） |
| ② | 灰底列表里的任意一行 | `click → onTodoClick` · `js/app.js:14` · **父元素** | 提示「绑定在父元素 `ul#todo-list` 上（可能是事件委托）」，高亮第 14–18 行 |
| ③ | `清空` 按钮 | `click → onReset` · `js/app.js:27` · 精确 | 绑定对象写的是变量 `reset`，仍能回到 `#reset`；高亮 27–31 |
| ④ | `内联脚本绑定` 那行 | `click → onNoteClick` · `index.html:<行号>` · 内联 | 高亮的是本 HTML 文件里那段内联 `<script>` |
| ⑤ | 灰区 `灰区` 两个字 | 无命中 | 显示「未在源码中找到直接绑定，可能通过事件委托注册」；下方「页面级监听」里能看到 `keydown → onKeydown`；并注明「另有 1 处绑定无法静态归属」 |

再补三条不属于清单但值得确认的：

- **HTML 段**：每个方块都指向 `index.html` 里那一行，`保存` 按钮这种交互元素也一样（靠 `data-lh` 标注），
  打开标签里能看到 `id="btn" class="primary"`，`data-lh` 这类插桩属性不会露出来。
- **样式段仍在**：随便点一个方块，规则照旧按 specificity 列出，点进去跳到 CSS 并高亮整条 —— 三段共用一次点击。
- **段头摘要**：折叠状态下也能看到「`index.html:14` · 精确 / 4 条规则命中 / 1 处绑定」，0 条时那一栏给的是解释而不是空白。

## 这份示例同时验证了这些实现细节

- **静态分析，不是运行时**：`app.js` 里的绑定没有一条是运行时抓的，全靠源码符号表；页面本身在预览里是 `runScripts=outside-only` 也一样能定位。
- **选择器匹配**：`getElementById("btn")` 归一成 `#btn` 再和点击元素比，不是拿元素文本回源文件搜。
- **变量间接绑定**：`const reset = document.getElementById("reset"); reset.addEventListener(...)` 靠变量表连回去；换了名字也不用改面板。
- **事件委托降级**：点 `<li>` 只能定位到父元素 `#todo-list` 上的那次 `addEventListener`，抽屉里会明说是父元素、标「推断」。
- **内联 `<script>` 收录**：`index.html` 里的脚本行号偏移到 HTML 的真实行，跳转打开的就是 HTML 文件。
- **归属不明的绑定**：`function bindHover(el) { el.addEventListener(...) }` 的绑定对象是参数，静态上判不了 → 计入「无法静态归属」，不冒充命中。
- **页面级监听**：`document.addEventListener("keydown", ...)` 单独列在「页面级监听（可能经由事件委托触发）」里。
- **未找到就是未找到**：灰区那句提示是写死的原话，不会硬编一条最像的给你。

## 自动化

同一份示例也被 `src/lib/locate/jsDemo.test.ts` 用着：真正插桩 + 内联，在 jsdom 里逐个点击上面这些
元素，把 bridge 回传的 `element/ancestors` 丢进 acorn 索引反查，比对事件名、函数名、`文件:行`、
高亮区间与委托提示；再用 `lh-element.range` 校验抽屉 HTML 段的行号。改这个示例时，那边会一起红。

## 边界（示例故意没做的部分）

- 运行时动态注册的监听（`setTimeout` 里再 `addEventListener`、框架渲染后挂载）定位不到。
- `el.addEventListener` 里 `el` 是参数 / `this` / `querySelectorAll().forEach()` 的回调参数时，归属不到具体元素。
- 带属性选择器（`[data-x]`）的查询只能识别「形状不可判」，不硬说命中。
- Vue / React 等框架生成的 DOM：源码里没有对应的查询与绑定，面板会如实说未找到。
